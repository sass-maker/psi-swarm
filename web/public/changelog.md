# psi-swarm changelog

Verified milestones for the local-first distributional Lighthouse tracker.

## July 3, 2026 — Complete local web workflow

The `psi-swarm web` command starts the local agent and opens the browser controller. Operators can run, compare, and inspect swarms while compute and history remain local.

## July 2, 2026 — Guarded manual releases

The repository deploy command verifies the intended workflow and build before a human-triggered production release.

## June 26, 2026 — Privacy-safe public demo

The deployed controller stopped probing localhost unless the visitor is on localhost or explicitly supplies agent intent.

## June 13, 2026 — v0.4.0 evidence workflows

Local regression watchlists, a static demo gallery, and saved trace insights shipped together.
