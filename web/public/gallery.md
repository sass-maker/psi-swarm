# psi-swarm demo gallery

The demo gallery contains curated, static before-and-after examples of psi-swarm output. Unlike the controller pages, it works without a local agent.

## What the examples demonstrate

- Distributional results across repeated Lighthouse runs
- Before-and-after percentile comparisons
- Evidence-backed performance diagnoses
- The difference between a representative distribution and one noisy score

The fixtures are demonstrations, not live measurements of the visitor's site.
