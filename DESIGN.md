# Design

## Direction

Preserve psi-swarm’s local performance-console identity: deep navy surfaces, cyan measurement accents, system typography, monospace data labels, and minimal static Astro chrome.

## Rules

- Reading surfaces inherit the web app’s existing color tokens.
- Cyan identifies primary navigation, actions, and measurement metadata.
- Keep layouts lean, responsive, and compatible with a fully static deployment.
- Product copy emphasizes repeated measurements, percentile evidence, and local compute.
